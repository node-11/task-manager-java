# Task Manager System (Java)

A simple console-based Task Manager application developed using Java.

## Features
- Add Task
- View Tasks
- Update Task
- Delete Task
- Mark Task as Completed

## Technologies Used
- Java
- ArrayList
- Scanner
- Loops & Conditional Statements

## Purpose
This project demonstrates basic CRUD operations in Java and helps practice programming fundamentals.

## How to Run
1. Open in any Java IDE (NetBeans / IntelliJ / Online Compiler)
2. Run Main.java
3. Use menu options in console
